The server

nginx: the receptionist who reads the name

Many sites share one IP address. nginx reads which name the visitor asked for and follows the matching rule.

http://leelagarden.com.np

Redirect to https://, the secure version

https://www.leelagarden.com.np

Redirect to https://leelagarden.com.np

https://leelagarden.com.np

Renderer · 127.0.0.1:3001, the website

https://admin.leelagarden.com.np

Admin app · 127.0.0.1:3000, the dashboard

https://api.sites.surajthapa247.com.np

API · 127.0.0.1:4000

The rules for this domain live in /etc/nginx/atrium-domains/leelagarden.conf on the VPS.

nginx is a reverse proxy: it is the only program facing the internet, and it forwards each request to the right app behind it. With HTTPS it learns the requested name at the very start of the connection (that is called SNI), so it can also pick the right certificate. Plain http and www both get a 301 redirect, which tells browsers and Google that https://leelagarden.com.np is the one true address.
