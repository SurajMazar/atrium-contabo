Cheat sheet

Words you'll meet

DNS

The system that turns names into IP addresses.

Nameserver

Holds a domain's records. Yours: Cloudflare.

Resolver

Looks names up for you and caches the answers.

TTL

How long an answer may be remembered.

A record

Name to address: @ to 169.58.157.28.

CNAME

Name to another name. Not allowed on the root.

TXT record

Free text in DNS; here, proof of ownership.

VPS

Your rented Contabo server: 4 CPUs, 8 GB.

Port

A numbered door: 443 is HTTPS, 5432 Postgres.

Reverse proxy

A front server (nginx) passing requests to apps.

Certificate

Signed proof of identity that makes HTTPS work.

Host header

The part of a request naming the site asked for.

Keep this slide handy when reading Cloudflare, certbot or nginx documentation; these twelve words cover almost everything in this deck.
