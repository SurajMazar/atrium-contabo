Same trip, different door

admin.leelagarden.com.np

1

DNS and nginx

Its A record points to the same VPS. nginx sends this name to the admin app (port 3000), with its own certificate.

2

Branding by name

The sign-in page asks the API who owns this hostname. It is saved as Leela Garden's admin domain, so the page shows Leela Garden's name and logo.

3

Trusted for sign-in

Because it is a saved admin domain, the API accepts sign-ins from it automatically. New accounts come by invitation only.

Set it as a super admin: Organizations, the organization's menu, Admin domain…

The admin domain follows the same path as the website up to nginx; nginx then sends it to the dashboard app instead of the renderer. The dashboard reads the hostname in the browser and asks the API for branding, which is how one dashboard can look like Leela Garden on admin.leelagarden.com.np and like Atrium on admin.sites.surajthapa247.com.np. Browsers block sign-ins from unknown sites, so the API keeps a list of trusted addresses; saved admin domains are added to it automatically, within a minute.
