# How custom domains work (deck)

A beginner-friendly, 21-slide walkthrough of one visit to `leelagarden.com.np`: DNS, verification, the
firewall, nginx, HTTPS, the renderer, plus a reCAPTCHA case study, a checklist and a glossary.

- **View:** open `index.html` in a browser. Arrow keys move, **N** shows the speaker notes, **F** goes
  full screen. Google Fonts are loaded online; it still works offline with fallback fonts.
- **Edit:** the slides are `source/slides/<id>.html` (order and sections in `source/deck.json`). After
  editing, run `python3 build.py` to regenerate `index.html`.
- **Online version** (editable, exports to PowerPoint/PDF from its Share menu):
  https://claude.ai/artifact/83WVkG19HkuK7KfgjNa5A6
